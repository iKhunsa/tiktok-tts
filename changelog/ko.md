## [1.11.2] — 2026-10-09

### 채팅 모더레이션
- 새로운 **Rust Chat Guard** 엔진이 기본적으로 관찰 모드로 켜져 있습니다(아무것도 막지 않고, 걸러냈을 메시지만 기록합니다).
- 설정에 **「채팅 모더레이션」** 블록 추가: 단계, 언어, 허용 단어, 차단 단어, 엔진 상태.
- 필터 언어가 TTS **음성 언어를 자동으로 따라갑니다**.
- 대기열 배지에서 **차단된 메시지** 팝업을 열 수 있습니다(차단됨, 단어, TTS 대기열).
- 차단 단어 관리를 하나로 통합하고 **계정별로 저장**합니다(이전 형식에서 자동으로 옮겨집니다).
- 필터가 guard의 판정을 따르고, 모더레이션 조치는 즉시 저장됩니다.
- **의미 없는 텍스트** 필터 추가(「asdfghjkl;」 같은 아무렇게나 친 키): 누군가 여러 번 연속으로 보내면 메시지는 채팅에 보이지만 읽어 주지 않습니다. 기본으로 켜져 있으며 설정 > 「채팅 모더레이션」에서 「알림만」이나 「끄기」로 바꿀 수 있습니다. 누구도 자동으로 음소거하지 않습니다: 그건 당신이 결정합니다. 실제 단어, 웃음(`jajaja`, `wkwkwk`, `ㅋㅋㅋ`), 이모트, 링크가 들어간 메시지는 표시되지 않습니다.
- 차단된 메시지 팝업에서 의미 없는 텍스트에는 스패머를 막고 싶을 때 쓸 수 있는 **「사용자 음소거」** 버튼이 있습니다.
- `.json` 파일에서 **차단 단어 가져오기**, 3단계 마법사 제공: 「형식」(바로 복사할 수 있는 예시), 「가져오기」(파일을 끌어다 놓거나 선택), 「확인」(새 단어 수와 미리보기). 단어는 기존 목록에 추가되며, 목록을 대체하지 않습니다.

### OBS 오버레이

- 채팅, Top Likers, **Top 후원자**를 「사용자 지정」에서 모두 설정 가능; 아바타, 역할(모더레이터/구독자), 아바타에 플랫폼 말풍선이 달린 링.
- 연결하지 않아도 되는 **예시 데이터 미리보기**(4개 플랫폼 채팅, 고정 알림).
- Follow/Share 알림을 단순화하고 Top Likers에 강조 색상을 추가했습니다. 사용자 지정 배경은 제거되었습니다.

### 채널

- 채널 연결 재시도 횟수가 시도 사이에 유지됩니다.
- 더 빠른 시작(TikTok 클라이언트는 사용할 때만 불러옵니다).

### 인터페이스
- **음성 및 오디오**를 창 너비에 맞춰지는 3개의 카드로 리디자인.
- **키보드 단축키를 탭으로**: TTS와 채팅, 음악, 일반.
- 설정의 기호를 SVG 아이콘으로 교체, 누를 때 피드백, 채널 스타일 통일.
- 이벤트 효과와 연결 실패 알림.
- 새 소식에 YouTube 영상 삽입.
- **MCP** 에이전트 연결을 간단하게(더 명확한 스니펫).
- 이제 앱을 끄지 않고 창을 닫을 수 있습니다. 설정에서 **닫을 때 트레이로 최소화**를 켜면, X를 눌렀을 때 TikLiveTTS가 시스템 트레이(시계 옆)로 숨어서 계속 채팅을 읽어 줍니다. 완전히 종료하려면 아이콘을 오른쪽 클릭하고 **종료**를 선택하세요. 기본은 꺼져 있으므로, 켜기 전까지는 X가 예전처럼 앱을 닫습니다.
- 새 옵션 **Windows 시작 시 열기**: PC를 켜면 TikLiveTTS가 자동으로 실행되어, 방송을 시작할 때 이미 준비되어 있습니다.

### 수정 사항
- 대기열 배지 문구를 명확하게 하고 언어를 불러올 때 다시 그립니다.
- Pro 배너가 앱을 열 때마다 다시 표시됩니다.
- 10개 언어 모두의 깨진 텍스트(mojibake)를 고치고 새 키를 번역했습니다.
- 채널 튜토리얼이 숨겨진 요소를 가리키던 문제와 로그인 후 TikTok 로그인 화면이 사라지지 않던 문제를 수정했습니다.
- 채팅 오버레이의 플랫폼 칩이 선택 상태를 잘못 표시하던 문제를 수정했습니다.
- 새로 설치할 때의 기본 사이드바(채팅, 오버레이, Clips, 모더레이션).
- Soundpad가 받은 목록을 더 꼼꼼히 확인합니다; 시뮬레이션 채팅 메시지에 고유 id 부여.
- TTS: 멈춘 오디오를 끊고 텍스트 길이를 제한합니다.
- `--user-data-dir`을 명시적으로 지정하면 그대로 따릅니다.
- 인터페이스의 아이콘, 창, 상태를 여러 군데 다듬었습니다.
- 차단 단어 가져오기에서 형식이 잘못된 파일을 더 이상 받지 않습니다: 깨진 JSON이나 단어 목록이 아닌 파일은 일반 오류를 내거나 목록을 쓰레기 텍스트로 채우는 대신, 명확한 알림과 함께 거부됩니다.
- 더 똑똑해진 TikLiveTTS 음성 안내: 첫 안내는 15분에 나오고, 이후에는 많아야 25분마다, 그리고 방송에 사람이 있을 때만 나옵니다. 방송이 비어 있으면 그냥 나오지 않고 시청자가 올 때까지 기다립니다. 예전에는 너무 자주 반복되거나 한참 동안 나오지 않을 수 있었습니다. Pro 요금제에서는 나오지 않습니다.
- 닉네임의 긴 숫자를 더 이상 읽지 않습니다: `pablito434435433453`은 「pablito」로 읽고, 고유한 이름이 없는 계정(`user14423423…`, `usuario14423423…`)은 앱 언어로 「사용자」라고 읽습니다. 채팅과 입장, 팔로우, 선물, 좋아요, 공유 안내에 모두 적용됩니다. 숫자가 적은 이름(`lu15`, `pablo2024`)은 예전처럼 읽고, 화면, OBS, 랭킹에서는 닉네임이 그대로 전부 보입니다.
- 음악 봇: YouTube 링크로 신청곡(`!p https://youtu.be/...`)을 보내면 다시 그 곡이 재생됩니다. 이전에는 링크가 사라져 봇이 «link»라는 단어로 검색했고, 그래서 다른 곡이 재생됐습니다. 채팅과 음성에서는 링크가 계속 «link»로 표시됩니다.
- 음악 봇: YouTube 엔진이 이제 다음 안정 버전을 몇 주씩 기다리지 않고 수정이 나온 당일에 업데이트되어, YouTube가 무언가를 바꿔도 신청곡이 훨씬 빨리 다시 작동합니다. 음악 재생 중이라 엔진 업데이트가 중간에 멈췄다면, 다음에 앱을 열 때 자동으로 마무리됩니다.
- Kick: 채팅이 다시 연결됩니다. Kick이 라이브 채팅에 쓰는 시스템을 바꾸면서 앱이 채팅을 읽지 못하고 연결에 실패했습니다. 이제 Kick의 새 시스템을 사용하며, 여전히 계정이나 로그인이 필요 없고 방송 내내 연결이 자동으로 유지됩니다.
